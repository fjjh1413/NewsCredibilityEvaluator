# 智闻辨真：UI/UX 设计系统设计规范 (design_system.md)

本设计系统旨在为“智闻辨真”新闻可信度评估系统确立统一的视觉语言、界面原则及交互规范，主要面向高保真原型展示、答辩演示及求职作品集呈现。系统倡导 **“Swiss Minimalist & Professional Trust”**（瑞士极简与专业信任感）设计哲学，强调高对比排版、网格对齐、克制色彩与直观的层级结构。

---

## 1. 颜色 tokens 规范 (Color Tokens)

设计系统使用以下命名的 CSS 变量进行色彩映射，以确保用户端与管理端的视觉一致性。

### 1.1 品牌与页面基础色

| 变量名 | 推荐色值 (Hex) | 用途说明 |
| :--- | :--- | :--- |
| `--color-primary` | `#0369a1` (科技蓝) | 主交互色、主要按钮、聚焦状态、高亮链接 |
| `--color-primary-strong` | `#0c4a6e` (深海蓝) | 标题文字、导航栏背板、强调字体、核心品牌标志 |
| `--color-primary-soft` | `#e0f2fe` (极浅蓝) | 主交互色微亮背景、悬浮选中背景、次级高亮框 |
| `--color-accent` | `#0ea5e9` (AI活力蓝) | 向量检索/AI 生成的专用指示色、图标微光、进度条装饰 |
| `--color-bg-page` | `#f5f9fc` (极浅冷灰) | 页面整体背景色。避免纯白（`#ffffff`）在大屏下导致的视觉疲劳 |
| `--color-bg-panel` | `#ffffff` (纯白) | 卡片、面板、弹窗、抽屉等悬浮层的主底色 |
| `--color-bg-subtle` | `#f8fafc` (蓝灰微调) | 弱分区背景、表格头部背景、禁用输入框底色 |

### 1.2 风控与语义状态色

风险评估系统的等级采用多重通道表达（颜色+文本+图标+底色），避免红绿色盲用户产生歧义。

| 风险等级/语义 | 变量名 (文字) | 推荐色值 (Hex) | 变量名 (背景) | 背景色值 (Hex) | 用途说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **可信新闻** (80-100分) | `--color-success` | `#16a34a` (绿) | `--color-success-soft` | `#dcfce7` | 通过评估，风险极低，合规通过 |
| **存疑信息** (60-79分) | `--color-warning` | `#d97706` (琥珀黄) | `--color-warning-soft` | `#fef3c7` | 存在信息不完整，需小心查证 |
| **疑似谣言** (40-59分) | `--color-orange` | `#f97316` (深橙) | `--color-orange-soft` | `#ffedd5` | 风险特征明显，存在刻意误导特征 |
| **高风险谣言** (0-39分) | `--color-danger` | `#dc2626` (鲜红) | `--color-danger-soft` | `#fee2e2` | 极高传播风险，系统强力警示阻断 |

### 1.3 中性文字与边框色阶

| 变量名 | 推荐色值 (Hex) | 用途说明 |

## 2. 字体与排版比例 (Typography)

为保证阅读效率与学术风控产品的严肃感，排版需高度规范化。

### 2.1 字体族

```css
font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", "Noto Sans SC", "PingFang SC", "Microsoft YaHei", sans-serif;
```

* 优先使用系统原生现代无衬线字体。
* 在 Windows 平台下优化微黑渲染，不使用衬线字（如宋体）或过于圆润的拟人化字体。

### 2.2 字号与层级规则

字体缩放比率基于严格的梯度，严禁在页面中随意设定奇数字号：

| Token 变量 | 对应字号 (px) | 字重 (Weight) | 典型应用场景 |
| :--- | :--- | :--- | :--- |
| `--font-size-xs` | `12px` | 400 / 500 | 辅助提示、时间戳、表格辅助列、Tag 内文字 |
| `--font-size-sm` | `13px` | 500 / 600 | 表格内容、辅助输入提示、下拉菜单选项 |
| `--font-size-base` | `14px` | 400 / 600 | 页面正文、默认输入框内容、标准按钮文本 |
| `--font-size-md` | `16px` | 600 | 卡片标题、模块子标题、侧边栏导航文字 |
| `--font-size-lg` | `20px` | 700 | 二级页面标题、弹窗/抽屉主标题、报表组名称 |
| `--font-size-xl` | `24px` | 700 | 页面大页头主标题、登录注册标题 |
| `--font-size-score`| `48px` | 800 | 检测结果页 final_score (特大评分数字) |

## 3. 8px 间距网格系统 (Spacing Grid)

所有元素的 margin、padding、内缩距及布局栅格必须是 8px 的倍数，以形成韵律化的视觉结构。

* **`--space-1` (4px)**：极微小间距，如标签内文字与小图标的微调间距。
* **`--space-2` (8px)**：紧凑间距，如按钮内文字图标间距、Tag 间距、表单项间的纵向微调。
* **`--space-3` (12px)**：中等紧凑，如紧凑表格行高、卡片头部 Padding。
* **`--space-4` (16px)**：标准元素间距，如小卡片内边距、面包屑与标题的间距。
* **`--space-5` (20px)**：表单项纵向间距、侧栏菜单项间距。
* **`--space-6` (24px)**：页面主体卡片 Padding、区块间距。
* **`--space-8` (32px)**：大页面主分区横向 Padding、大图表间距。
* **`--space-10` (40px)**：首屏英雄区（Hero Zone）纵向间距、登录注册页顶部留白。

## 4. 界面几何与圆角 (Border Radius)

避免采用过度低龄化的圆润胶囊形态，同时摒弃完全直角的刺硬感，采用微圆角方案表达科学与精确性。

* **微圆角 `var(--radius-sm)` (4px)**：用于表格内的状态标签 (Tag)、多选框、单选框、小图标背板。
* **标准圆角 `var(--radius-md)` (6px)**：用于默认按钮 (Button)、输入框 (Input)、下拉选择框 (Select)、导航项。
* **大圆角 `var(--radius-lg)` (10px)**：用于内容卡片 (Card)、列表容器、弹窗面板 (Modal)、侧边抽屉 (Drawer)。
* **极限圆角 `var(--radius-full)` (999px)**：仅用于纯圆形元素（如头像占位、完全胶囊型的风险等级数字标识）。

## 5. 阴影体系 (Shadows)

系统阴影必须极浅、极软，仅用于区分卡片悬浮层与背景，不可大面积涂抹脏灰色。

* **无阴影**：背景页面上的平铺基础面板，使用 `1px solid var(--color-border)` 勾勒轮廓即可。
* **低悬浮 `var(--shadow-card)`**：
  ```css
  box-shadow: 0 8px 24px rgba(15, 23, 42, 0.04);
  ```
  用于主页面的普通内容卡片，建立视差但保持呼吸感。
* **悬浮聚焦 `var(--shadow-hover)`**：
  ```css
  box-shadow: 0 12px 30px rgba(15, 23, 42, 0.08);
  ```
  用于卡片悬浮 hover 态、下拉菜单滑出态。
* **核心交互聚焦 `var(--shadow-focus)`**：
  ```css
  box-shadow: 0 0 0 3px rgba(14, 165, 233, 0.18);
  ```
  输入框、按钮被 Tab 键定位或聚焦时的蓝色外层呼吸晕，符合无障碍访问 (A11y) 规范。
* **顶层模态 `var(--shadow-modal)`**：
  ```css
  box-shadow: 0 20px 48px rgba(15, 23, 42, 0.16);
  ```
  用于弹窗对话框、侧边滑动抽屉，强化遮罩层之上的视差深度。

## 6. 响应式与栅格断点 (Responsive Rules)

静态原型需完全兼容主流答辩及生产设备：

### 6.1 物理尺寸约束
* **内容最大宽度**：`1280px` (`--container-width`)，在宽屏下横向居中，防拉伸。
* **页面左右安全边距**：
  * 大于 1200px (1920x1080 桌面)：`32px`
  * 1024px ~ 1200px (1366x768 笔记本)：`24px`
  * 768px ~ 1023px (平板端)：`20px`
  * 小于 768px (手机端)：`16px`

### 6.2 移动端收缩原则 (Media Queries)
* **用户端顶栏**：在宽度小于 `768px` 时，顶部横向导航自动隐去，转化为汉堡包滑出菜单或纵向堆叠布局。
* **管理端侧栏**：在宽度小于 `1024px` 时，侧栏从固定占位转为隐藏悬浮（通过 JS toggle 唤出）或顶部横向轮播菜单。
* **栅格收叠**：所有的两栏布局（如检测输入页的“主输入+右侧栏”、首页的“核心卡片网格”）在小于 `980px` 时一律自适应折行为单列排列，宽度 100%。

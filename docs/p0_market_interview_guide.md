# P0 市场访谈与问题验证指南

## 目标

在进入耐久执行和 Human-in-the-loop 开发前，确认内容审核、品牌公关、校园媒体或企业舆情团队是否确实存在“证据收集与初筛耗时高”的问题。访谈用于发现事实，不用于向受访者推销既定方案。

P0 目标是完成至少 5 次、理想 8 次访谈，并覆盖至少 2 类角色。没有实际访谈记录时，只能说“问题有外部市场信号”，不能说已经验证付费意愿或产品市场匹配。

## 招募对象

- 内容平台审核、编辑或社区运营人员。
- 品牌公关、舆情分析或风险控制人员。
- 校园媒体、地方媒体或事实核查志愿者。
- 经常需要确认公开信息真实性的研究或咨询人员。

## 访谈问题

1. 最近一次需要核查新闻或公开信息是什么？请按实际步骤复盘。
2. 哪一步最耗时间？一次通常需要多久？
3. 会查看哪些来源？如何判断来源值得信任？
4. 遇到来源冲突时如何处理？最终由谁承担决定责任？
5. 哪类错误后果最严重：错误放行、错误拦截，还是处理过慢？
6. 当前使用哪些工具、表格或内部系统？在哪些地方需要复制粘贴？
7. 什么情况下必须升级给资深人员或主管复核？
8. 如果系统自动拆解主张、收集证据并给出待复核队列，哪部分最有价值？
9. 哪些数据不能发送给外部模型或搜索服务？
10. 如何衡量一个月内这类工具是否真的有用？

不要直接询问“你会不会买这个产品”。先询问当前成本、已有预算、采购方式，以及是否为相似工具付过费。

## P0 决策门槛

继续进入 B2B 风控工作流：至少 3 位受访者主动提到证据收集、来源比较或审计留痕耗时，并能提供可量化频率或耗时。

调整目标用户：问题存在，但主要发生在另一个角色或流程中。

停止商业化假设、保留求职项目：多数目标用户核查频率很低、没有责任压力，或现有免费渠道已经足够。

## 建议记录的基线指标

- 每周需要核查的内容数量。
- 单条内容平均与 P90 核查耗时。
- 每条内容查看的独立来源数量。
- 升级人工复核的比例。
- 错误放行和错误拦截的相对成本。
- 可接受的系统响应时间及单次成本。
